# Aura - Velas Aromáticas 

## Sobre o projeto

A Aura é uma loja virtual de velas aromáticas desenvolvida como projeto escolar do curso técnico em Tecnologia da Informação do Senac.

O objetivo do projeto é desenvolver um e-commerce funcional, utilizando PHP e MySQL, com uma interface delicada, floral e padronizada.

## Tecnologias utilizadas

- HTML
- CSS
- Bootstrap
- PHP
- MySQL
- PDO
- XAMPP
- Git e GitHub
- JavaScript

## Funcionalidades

- Vitrine de produtos
- Busca e filtro por categorias
- Detalhes dos produtos
- Cadastro e login de clientes
- Carrinho de compras
- Finalização de pedidos
- Pagamento simulado
- Controle de estoque
- Painel administrativo
- Cadastro, edição e exclusão de produtos
- Visualização de pedidos
- Validação de formulários com JavaScript
- Confirmação antes de excluir produtos

## Como executar o projeto

1. Instale o XAMPP.
2. Coloque a pasta aura dentro da pasta htdocs.
3. Inicie o Apache e o MySQL.
4. Importe o arquivo database/schema.sql pelo phpMyAdmin.
5. Crie uma cópia do arquivo .env.example com o nome .env.
6. Configure os dados de conexão com o banco.
7. Acesse http://localhost/aura/.

## Acesso administrativo

Cadastre uma conta pelo site e altere o campo tipo do usuário para admin na tabela usuarios, pelo phpMyAdmin. Depois, entre novamente na conta.

## Observação

Este projeto possui finalidade educacional. Os pagamentos são simulados e não envolvem transações financeiras reais.

## Requisitos do sistema

- PHP 8 ou superior
- MySQL ou MariaDB
- Apache (XAMPP)
- Navegador web

## Construção do sistema

**Identidade visual:** criação de uma interface delicada, com tons suaves e elementos florais, seguindo a proposta da loja de velas aromáticas.

**Vitrine:** organização das velas por categorias, apresentação das imagens, descrições e preços.

**Sistema de compras:** integração do cadastro de clientes, carrinho, formas de pagamento e controle de estoque.

**Administração:** gerenciamento dos produtos e acompanhamento dos pedidos realizados.

**Testes:** verificação das páginas, conexão com o banco de dados e funcionamento dos recursos em JavaScript.
